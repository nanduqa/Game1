# Game1 - Physics Playground

A browser-based HTML5 + JavaScript physics playground game with polished canvas visuals.

## How to run

From the repository root (`/tmp/workspace/nanduqa/Game1`), start a static server and open in a browser:

```bash
python -m http.server 4173
```

Then open:

- `http://127.0.0.1:4173/index.html`

## Gameplay

- 5 levels: Ramp, Spring, Pendulum, Buoyancy, Friction
- 5 activities per level (25 total)
- Interactive physics sliders + prediction challenges
- HUD with prop, concept, activity number, and score
- Completion screen with total stars (1-3 stars per activity)
